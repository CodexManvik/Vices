
  # Vices App UI Design

  This is a code bundle for Vices App UI Design. The original project is available at https://www.figma.com/design/BPfDVG6vq6y0MnN9Aou2fG/Vices-App-UI-Design.

  ## Running the code

  This project uses **pnpm** as its package manager (required due to pnpm overrides in package.json).

  Run `pnpm install` to install the dependencies.

  Run `pnpm dev` to start the development server.
